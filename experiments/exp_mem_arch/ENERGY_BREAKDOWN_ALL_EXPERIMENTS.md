# 全实验能耗明细

本表由 `data/summary_hbm3e.csv` 中 `drampower=on` 的 48 组实验生成。
`ACT/READ/WRITE/REF/Background` 使用 `drampower_*` 字段；`MAC` 从 `data_drampower/result_*.csv` 的 `t2t` 行均值提取。

口径说明：

- `DRAM J/step` 是一个 active batch decode step 的 DRAMPower-style DRAM 总能耗。
- `DRAM J/token` = `DRAM J/step / tokens_per_step`。
- `DRAM 内占比` 的分母是 `drampower_total_energy`，不包含 MAC。
- `含 MAC 占比` 的分母是 `drampower_total_energy + mac_energy`。
- 当前 48 组中 `all_act/read/write` 和 `ref` 均为 0；CSV 保留这些列，Markdown 简表省略 `all_*`。

完整 CSV：`data/energy_breakdown_all_experiments.csv`。
