# Ramulator-on DRAMPower REF Energy Breakdown

本报告只统计重新运行后的 24 个 `Ramulator=on, DRAMPower=on` HBM3E 实验。
ACT、READ、WRITE、REF 计数全部来自 Ramulator controller 的 issued command counter；没有再混用上层 LLMSimulator 的 ideal/frontend 指令估算。

## 数据来源与口径

- 原始结果：`data_drampower_ramulcmd_ref/result_hbm3e_b{B}_l{L}_reorder_{on|off}_ramul_on.csv`
- 聚合 CSV：`data/energy_breakdown_ramulator_on_drampower_ref.csv`
- 每个实验有 3 条 `t2t` 行；表中数值为 3 次 decode step 的平均值。
- `J/step` 表示一个 active batch decode step 的能耗，即当前 batch 中每条序列各生成 1 个 token 的整批能耗。
- `J/token = J/step / tokens_per_step`，其中 `tokens_per_step = batch_per_gpu * 32`。
- `DRAM 内占比` 的分母是 `drampower_total_energy`，不包含 MAC；`含 MAC 占比` 的分母是 `drampower_total_energy + mac_energy`。

## 计数和能耗来源

- Ramulator command 记录：`src/dram/ramulator2/src/dram_controller/controller.h` 中 `record_issued_command()` 把 ACT/RD/WR/refreshing command 分别累计到 `kACT/kREAD/kWRITE/kREF`。
- REF 产生：`src/dram/ramulator2/src/dram_controller/impl/refresh/all_bank_refresh.cpp` 中 `AllBankRefresh` 每到 `nREFI` 对每个 rank 插入 all-bank-refresh 请求。
- LLMSimulator 取数：`src/dram/dram_interface.cpp` 的 `updateStatus()` 读取 `memory_system->get_issued_dram_cmd()` 的增量，再写入 `ExecStatus.{act,read,write,ref}_count`。
- DRAMPower-style 计算：`src/module/module_graph.cpp` 把 `ExecStatus` 转成 `CommandCounters` 后调用 `HBM3EAdapter::calculate()`。

当前 adapter 的单计数能耗为：

| 项 | nJ/count | 说明 |
|---|---:|---|
| ACT | 219.0336 | `max(VDD*(IDD0-IDD2N)*(tRCD+tRAS+tRP)*tCK, fallback_act) * 128` |
| READ | 114.0480 | fallback READ 主导，乘 `command_parallelism=128` |
| WRITE | 114.0480 | fallback WRITE 主导，乘 `command_parallelism=128` |
| REF | 2611.2000 | `VDD*(IDD5-IDD2N)*tRFC*tCK * 128` |
| Background | 5.0688 nJ/ns | `VDD*IDD2N*background_time*128` |

## 主要观察

- 24 个 Ramulator-on 实验的 `ref_count` 全部非零；平均 REF count 范围是 72401 到 40805223 / step。
- Reorder on 时 DRAM 能耗仍由 READ 主导，平均 READ 占 82.4%，REF 平均占 0.6%。
- Reorder off 时 WRITE 和 READ 都很大，平均 READ 占 50.3%，WRITE 占 37.6%，REF 平均占 1.1%。
- REF 能耗不是主导项，但在长 sequence、reorder off 下会达到百 J/step 量级；最大组 `reorder=off, seq=8192, batch/GPU=256` 的 REF 能耗为 106.55 J/step。
- 旧的 `data_drampower/` Ramulator-on 结果中 `ref_count=0`，因此不应用于 REF 能耗分析；本报告应作为 Ramulator-on REF 能耗口径的结果。
